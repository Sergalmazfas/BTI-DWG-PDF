## 🔗 **Связь с основным проектом**

### 📊 **Архитектура системы:**

```
┌─────────────────┐    ┌─────────────────┐    ┌─────────────────┐
│  telegram-bot-  │    │   dwg-processor │    │dwg-processor-   │
│  commands       │───▶│                 │───▶│metadata         │
│  (основной)     │    │  (обработка)    │    │ (метаданные)    │
└─────────────────┘    └─────────────────┘    └─────────────────┘
         │                       │                       │
         ▼                       ▼                       ▼
┌─────────────────┐    ┌─────────────────┐    ┌─────────────────┐
│   GCS Storage   │    │   Forge API     │    │   Queue System  │
│ (файлы + очередь)│    │  (конвертация)  │    │  (задания)      │
└─────────────────┘    └─────────────────┘    └─────────────────┘
```

### 🔄 **Взаимодействие сервисов:**

1. **telegram-bot-commands** - основной сервис
   - Принимает файлы от пользователей
   - Добавляет задания в очередь
   - Отправляет уведомления

2. **dwg-processor** - обработчик
   - Берет задания из очереди
   - Конвертирует DWG в PDF через Forge
   - Сохраняет результаты

3. **dwg-processor-metadata** - метаданные
   - Обрабатывает дополнительную информацию
   - Подготавливает метаданные файлов
