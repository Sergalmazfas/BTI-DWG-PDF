# 📜 LISP Scripts для BTI Auto-Processor

AutoLISP скрипты для автоматической обработки чертежей БТИ.

---

## 📁 Файлы

### **BTI_APPLY.lsp**

**Назначение:** Автоматическое создание POINT-меток БТИ по меткам от Leica  

**Что делает:**
1. Создает стандартные слои БТИ (BTI_MARKERS, A-DOOR, A-WINDOW, и т.д.)
2. Находит метки на слоях MARK_DOOR, MARK_WINDOW
3. Создает POINT + TEXT метки (вместо блоков) для дверей и окон
4. Применяет стандарты БТИ к чертежу

**⚠️ ВАЖНО:** Скрипт использует POINT и TEXT вместо INSERT для совместимости с Forge accoreconsole.exe

**Использование в AutoCAD:**
```lisp
(load "BTI_APPLY.lsp")
BTI_APPLY
```

**Использование в Activity (Forge):**
```json
{
  "scriptFile": {
    "url": "https://.../BTI_APPLY.lsp",
    "localName": "BTI_APPLY.lsp"
  }
}
```

---

### **BTI_CLEANUP.lsp**

**Назначение:** Очистка временных слоев после обработки

**Что делает:**
1. Удаляет служебные слои (MARK_DOOR, MARK_WINDOW, TEMP)
2. Очищает неиспользуемые блоки и стили (PURGE)
3. Подготавливает чертёж к печати

**Использование:**
```lisp
(load "BTI_CLEANUP.lsp")
BTI_CLEANUP
```

---

## 🔄 Процесс обработки

```
1. Leica DISTO создает DWG
   └─ Контуры комнаты + метки (MARK_DOOR, MARK_WINDOW)

2. BTI_APPLY.lsp (или BTI_AUTO_APPLY.lsp):
   ├─ Создает слой BTI_MARKERS
   ├─ Создает POINT-метки по меткам
   ├─ Добавляет TEXT подписи (BTI_DOOR, BTI_WINDOW)
   └─ Применяет стандарты

3. BTI_CLEANUP.lsp:
   ├─ Удаляет временные слои
   └─ Очищает чертёж

4. Результат:
   └─ Готовый DWG с POINT-метками и подписями БТИ
```

---

## 📊 Слои для Leica

Для корректной работы, Leica должна экспортировать DWG с метками:

| Слой | Назначение | Что размещать |
|------|-----------|---------------|
| **MARK_DOOR** | Метки дверей | Линии или полилинии в местах дверей |
| **MARK_WINDOW** | Метки окон | Линии или полилинии в местах окон |

Скрипт автоматически найдет эти метки и вставит блоки БТИ.

## 🧪 Тестирование

### **Локально (в AutoCAD):**

```lisp
; 1. Загрузить скрипт
(load "BTI_APPLY.lsp")

; 2. Создать тестовые метки (вручную)
(command "_.LINE" '(0 0 0) '(100 0 0) "")
(command "_.CHPROP" "L" "" "LA" "MARK_DOOR" "")

; 3. Запустить обработку
BTI_APPLY
```

### **В Forge Activity:**

Используйте `activity_with_lisp.json` для регистрации Activity с LISP скриптами.
